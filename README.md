# HTML5 Semantic Structure & Accessibility Portfolio

## Overview
A multi-page personal portfolio website built to adhere strictly to modern semantic HTML5 standards and WCAG accessibility guidelines. This project was developed to demonstrate a perfect 100 score on Lighthouse Accessibility and SEO audits.

## Key Features
* **Semantic HTML5:** Strict utilization of tags like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` for proper document structure.
* **Accessibility (WCAG):** Implementation of ARIA labels, roles (`role="main"`, `role="banner"`), and strictly associated form labels to ensure full screen reader compatibility.
* **SEO Optimization:** Optimized meta descriptions and descriptive title tags for search engine visibility.
* **Keyboard Navigation:** A fully accessible, tab-navigable contact form using explicit `for` and `id` attributes.
