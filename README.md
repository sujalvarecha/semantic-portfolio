# 🌐 HTML5 Semantic Structure & Accessibility Portfolio

## 🚀 Overview
A multi-page personal portfolio website engineered to adhere strictly to modern semantic HTML5 standards and WCAG accessibility guidelines. This project was specifically developed to achieve and demonstrate a flawless 100 score on Lighthouse Accessibility and SEO audits.

## ✨ Key Features
* **Semantic Architecture:** Strict utilization of HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) to ensure a logical, highly readable document structure.
* **WCAG Compliance:** Comprehensive implementation of ARIA labels, specific landmarks (`role="main"`, `role="banner"`), and explicitly associated form controls for total screen reader compatibility.
* **SEO Optimization:** Strategically optimized meta descriptions and descriptive title tags to maximize search engine visibility.
* **Keyboard Accessibility:** A fully tab-navigable contact form built with explicit `for` and `id` attribute pairings, ensuring seamless use without a mouse.
